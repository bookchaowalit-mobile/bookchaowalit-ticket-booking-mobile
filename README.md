# Ticket Booking — Mobile

.NET MAUI cross-platform app for **Ticket Booking**.

Part of [Chaowalit Greepoke](https://bookchaowalit.com)'s 101 Portfolio Projects.

## Tech Stack

- **Framework:** .NET MAUI 8
- **Language:** C# / XAML
- **Targets:** Android, iOS
- **UI:** Native controls via MAUI abstractions

## Getting Started

```bash
dotnet workload restore
dotnet build
```
